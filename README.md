## 🎯 Цель проекта
Разработка современного, масштабируемого интернет-магазина одежды, который решает проблему неудобного подбора товаров за счёт детальной атрибутики (размерные сетки, цвета, бренды) и интуитивно понятного интерфейса. 

Проект представляет собой веб-приложение с разделением на клиентскую часть (для покупателей) и административную панель (для управления контентом).

### 🛠 Технологический стек
- **Backend:** C#, .NET 8/9, ASP.NET Core Web API
- **База данных:** PostgreSQL + Entity Framework Core (ORM)
- **Архитектура:** Clean Architecture с элементами CQRS (MediatR) для чистоты кода и лёгкости поддержки
- **Frontend:** React (или Blazor WebAssembly) + Tailwind CSS
- **Инфраструктура:** Docker, Docker Compose (контейнеризация), Swagger (документация API)

---

## ✅ Требуемый результат
Полнофункциональная e-commerce платформа для магазина одежды, включающая:
1. Клиентскую часть с каталогом, корзиной и оформлением заказов.
2. Административную панель для управления товарами, категориями и заказами.
3. Решение, развёрнутое в контейнерах и покрытое технической документацией.

## 📅 План выполнения работ (15 недель)

### 1️⃣ Этап 1. Проектирование и фундамент (недели 1–3)
- Разработка и согласование схемы базы данных (ER-диаграмма).
- Настройка репозитория, CI/CD пайплайна и архитектуры решения (Clean Architecture).
- Реализация модулей аутентификации и регистрации (JWT, роли: Пользователь / Админ).

### 2️⃣ Этап 2. Разработка ядра и каталога (недели 4–7)
- Реализация API и UI для управления категориями, товарами и их вариантами (размер, цвет, остаток на складе).
- Настройка загрузки и хранения изображений товаров.
- Реализация фильтрации и поиска по каталогу.

### 3️⃣ Этап 3. Бизнес-логика покупок (недели 8–11)
- Разработка модуля корзины (сохранение состояния).
- Реализация процесса оформления заказа (расчёт стоимости, выбор адреса, статусы заказа).
- Создание административной панели для просмотра и управления заказами.

### 4️⃣ Этап 4. Инфраструктура, тестирование и полировка (недели 12–15)
- Написание Unit-тестов для критической бизнес-логики (xUnit).
- Контейнеризация всего приложения (Backend, Frontend, БД) через Docker Compose.
- Финальное тестирование, исправление багов, написание технической документации (README).
